# Audit SELAH — 15 November 2026

## Lingkup dan perubahan

Fondasi berasal dari ZIP SELAH v0.3 milik owner, diekstrak ke checkout kosong `/workspace/selah`. Tidak dibangun ulang. Enam modul, sepuluh materi akademi, enam slot resmi, katalog dan baseline migrasi dipertahankan. Tidak ada dependency aplikasi baru, backend atau publikasi.

Ditemukan satu cacat PWA subpath: `id: "./"` pada manifest ditafsirkan Chromium relatif terhadap origin, sehingga identitas menjadi `/`, walaupun start URL dan scope `/selah/`. ID eksplisit dihapus agar identitas mengikuti start URL. Chromium mengonfirmasi identitas, scope dan start URL sekarang `/selah/`. Versi UI/app/cache diselaraskan ke 0.3.1; versi konten tetap karena katalog tidak berubah. Pemeriksaan regresi ditambahkan pada `tests/validate.mjs`.

## Hasil otomatis

Lulus setelah perubahan:

- `node tests/validate.mjs`: 38 profil, schema, ID unik, kategori, manifest/icon paths, keselarasan versi, portabilitas subpath.
- `node tests/catalog-merge.mjs`: overlay lokal, pembaruan/penambahan publik, penghapusan lokal, DOM ID.
- `node --check assets/app.js` dan `node --check sw.js`.
- Pemeriksaan katalog: 38 ID sama dengan baseline v0.2; 22 W dan 16 P; tanpa judul duplikat; seluruh lirik kosong. Validasi ini tidak membuktikan akurasi musikal, teologi atau izin karya.

Headless Chromium sistem, Playwright yang tersedia di environment, server Python pada subpath `/selah/`. Tidak memerlukan npm install. Harness sementara di `/tmp/selah-audit.cjs`, `/tmp/selah-extra.cjs`, dan `/tmp/selah-update.cjs`; ini bukti sesi, bukan test suite CI yang terpasang di repo.

Lulus:

- Navigasi sepuluh halaman pada lebar 360, 393, 768 dan 1280: tidak ada overflow horizontal dokumen. Tabel dan navigasi menggunakan scroll internal.
- Welcome, Open, buka ulang melalui footer, Enter keyboard dan pengembalian fokus navigasi. Salinan welcome dipertahankan; ayat ditandai parafrasa. Warna cream/merah/kuning dan referensi desain ditinjau; bukan pengujian visual lintas perangkat.
- Tambah lagu lokal dengan teks dummy asli, baca profil, edit key, reload, persistensi, hapus.
- Enam slot setlist; unduh TXT berisi WL uji; salin clipboard; pemanggilan print. Tampilan hasil cetak fisik belum diuji.
- Checklist, progres akademi dan refleksi; ekspor JSON, reset, impor kembali dan verifikasi progres/setlist/refleksi.
- Migrasi penyimpanan `musicMinistry.v1` dan impor backup schema v0.2 tanpa publishedBase. Menggunakan fixture buatan, bukan backup pribadi owner.
- Service worker mengontrol halaman; offline reload, pustaka 38 lagu, akademi dan refleksi tetap tersedia.
- Salinan fixture terpisah: pembaruan dan penambahan katalog melalui jaringan mempertahankan edit lokal; reset pustaka mempertahankan progres akademi.
- Salinan fixture terpisah: rilis shell 0.3.1 → 0.3.2, worker waiting, pesan pembaruan, tutup/buka tab, UI/cache baru, cache lama dibersihkan dan progres tersimpan. Versi 0.3.2 hanya fixture, tidak dikirim sebagai rilis aplikasi.

Satu assertion harness pembaruan sempat terlalu dini membaca pesan UI setelah worker waiting. Setelah harness menunggu kondisi pesan, siklus pembaruan lulus; tidak ada perubahan app untuk hal ini. Probe instalasi Chromium melaporkan `in-incognito`; bukan bukti instalasi perangkat.
